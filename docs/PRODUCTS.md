# Robux Developer Products

The 30 Developer Products to create on the Creator Dashboard (Monetization → Developer Products).
The price on the dashboard must match the one here, because the in-game buttons show the price from
`src/shared/Config.luau`. After creating a product, paste its ID into `src/shared/ProductIds.luau`
under the key shown here. Each product's image is `tools/art/products/<key>.png`.
